# 多物理场耦合仿真参考指南

> 基于中车株洲所 IGBT 多物理场仿真 & 比亚迪轮毂电机多学科集成平台技术拆解整理

## 1. 多物理场耦合仿真总览

### 1.1 耦合类型矩阵

| 耦合类型 | 物理场 | 典型应用 | 求解策略 |
|---------|--------|---------|---------|
| 热-电耦合 | 温度场 + 电流场 | IGBT 芯片结温、母排焦耳热 | 双向弱耦合 |
| 热-力耦合 | 温度场 + 应力场 | 焊层疲劳、热膨胀匹配 | 顺序耦合（先热后力） |
| 热-电-力三耦合 | 温度+电流+应力 | IGBT 封装可靠性 | 分步顺序耦合 |
| 电磁-结构耦合 | 电磁场 + 应力场 | 转子高速强度、磁致伸缩 | 单向（电磁→结构） |
| 电磁-热耦合 | 电磁场 + 温度场 | 电机损耗发热、涡流加热 | 双向迭代 |
| 电磁-热-结构三耦合 | 电磁+温度+应力 | 电机全耦合分析 | 顺序链式 |

### 1.2 求解策略选择

```
单向耦合 → 顺序求解（速度快，精度够）
 电磁→结构：电磁力作为结构载荷
 电磁→热：损耗作为热源
 热→结构：温度梯度作为结构载荷

双向耦合 → 迭代求解（精度高，耗时长）
 电磁↔热：温度影响电导率，损耗随温度变化
 热↔结构：热应力影响接触状态

全耦合 → 直接求解（最精确，最耗时）
 仅用于强耦合场景：压电、焦耳热-应力等
```

## 2. IGBT 器件多物理场仿真（热-电-力耦合）

### 2.1 器件层级结构（7层）

| 层级 | 材料 | 说明 |
|------|------|------|
| A | Cu | 铜主端子 |
| B | Pb-Sn 焊层 | 主端子与衬板焊层（关键研究对象） |
| C | Al | 衬板上覆金属层 |
| D | AlN | 衬板绝缘层 |
| E | Al | 衬板下覆金属层 |
| F | Pb-Sn 焊层 | 衬板与基板焊层 |
| G | AlSiC | 基板 |

### 2.2 材料参数库

| 位置 | 材料 | 热导率 W/(m·℃) | 密度 kg/m³ | 比热容 J/(kg·℃) | 弹性模量 GPa | CTE 10⁻⁶/K | 泊松比 |
|------|------|----------------|-----------|-----------------|-------------|-----------|--------|
| 基板 | AlSiC | 200 | 2960 | 760 | 230 | 7.5 | 0.254 |
| 衬板铝层 | Al | 238 | 2700 | 915 | 69 | 23.6 | 0.330 |
| 衬板绝缘层 | AlN | 165 | 3260 | 745 | 310 | 4.6 | 0.240 |
| 焊层 | Pb-Sn | 34 | 7380 | 167 | 45 | 17.6 | 0.300 |
| 主端子 | Cu | 398 | 8960 | 385 | 110 | 17.8 | 0.340 |
| IGBT/FRD芯片 | Si | 见公式 | 2320 | 713 | 112 | 2.5 | 0.280 |

**硅导热系数温度依赖：**
```
λ_Si(T) = A / (T - B)
其中 A = 320, B = 80（单位：W/cm·K）
```

### 2.3 Anand 粘塑性本构模型（焊层钎料）

焊层 Pb-Sn 在高温服役中存在弹性变形 + 塑性变形 + 蠕变，采用 Anand 模型描述。

**流动方程：**
```
dε_p/dt = A · exp(-Q/RT) · [sinh(ξσ/s)]^m
```

**内部状态变量演化方程：**
```
ds/dt = h₀ · |1 - s/s*|^α · sign(1 - s/s*) · dε_p/dt
s* = ŝ · [dε_p/dt / A · exp(Q/RT)]^n
```

| 参数 | 含义 | 典型值（Pb-Sn） |
|------|------|----------------|
| A | 常数 | 1591 MPa⁻¹ |
| Q | 活化能 | 60.3 kJ/mol |
| m | 应变率灵敏指数 | 0.232 |
| ξ | 应力乘子 | 7.0 |
| h₀ | 软硬化常数 | 9350 MPa |
| α | 软硬化应变率敏感指数 | 1.5 |
| ŝ | 饱和系数 | 80.4 MPa |
| n | 变形阻抗饱和应力敏感指数 | 0.153 |
| R | 气体常数 | 8.314 J/(mol·K) |
| T | 绝对温度 | K |

### 2.4 功率循环工况（GB/T 29332）

| 载荷步 | 时间 | 说明 |
|--------|------|------|
| 第1步 | 1s | 断→开转换 |
| 第2步 | 59s | 导通时间 |
| 第3步 | 1s | 开→断转换 |
| 第4步 | 59s | 关断时间 |
| 周期 | 120s | 分钟级功率循环 |

**芯片发热功率：**
- IGBT 芯片：1.69 × 10⁹ W/m³
- FRD 芯片：1.14 × 10⁹ W/m³

**散热边界条件：**
| 区域 | 对流换热系数 W/(m²·℃) |
|------|----------------------|
| 散热器 A 区 | 1,250 |
| 散热器 B 区 | 2,750 |
| 散热器 C 区 | 3,000 |
| 基板侧面（自然对流） | 15 |
| 环境温度 | 40℃ |

### 2.5 几何简化策略

- 忽略散热器几何 → 通过对流换热系数体现
- 忽略树脂外壳及硅胶 → 主要散热通道为散热器
- 忽略键合线 → 对温度分布影响很小

### 2.6 疲劳寿命预测模型

#### Coffin-Manson 模型（基于应变）
```
N_f = A · (Δε_in)^m
```
- m = -1.98, A = 0.159（Pb-Sn 参数）
- 参考结果：235,598 次

#### Darveaux 模型（基于能量）
```
N_0 = C₁ · (ΔW_avg)^C₂        # 起裂周期
da/dN = C₃ · (ΔW_avg)^C₄      # 裂纹扩展速率
```
- C₁ = 22400, C₂ = -1.52, C₃ = 5.86×10⁻⁷, C₄ = 0.98
- 参考结果：93,599 次

**模型选择建议：** Darveaux 更准确，能反映焊层含Sn相粗化的退化过程。

### 2.7 参数化研究方法

#### 孔洞率影响（生死单元技术）
```
研究范围：0%、2.5%、5.0%、10.0%
方法：生死单元技术模拟孔洞，正态分布随机生成位置
结论：孔洞率影响有限，循环周次降低幅度不大
```

#### 焊层厚度影响
```
研究范围：20μm ~ 120μm（步长20μm）
结论：循环周次随厚度增加呈先增后减，80μm附近为最优
```

## 3. 电机多学科仿真集成平台（电磁-结构-热）

### 3.1 四层分层式架构

| 层级 | 名称 | 核心职责 |
|------|------|---------|
| 第一层 | 表示层 | 用户交互界面，三大仿真模块入口 |
| 第二层 | 模型层 | 参数化模型配置与调用 |
| 第三层 | 持久层 | 数据管理器，CRUD操作 |
| 第四层 | 数据库层 | SQLite多学科数据库（9个专项库） |

### 3.2 三大仿真模块

#### 模块一：电磁学仿真
- **工具链：** RMxprt → Maxwell2D → PyAEDT
- **几何构建：** 定子→绕组→磁钢槽→永磁体→空气槽→转子
- **网格：** 绕组/磁钢细密，定子/转子适中，气隙四层加密
- **材料：** 铁心损耗系数（Kh/Ke/Kc）、永磁体矫顽力/电导率、BH曲线
- **输出：** 电磁转矩、转矩脉动、相/线电压、电磁损耗、磁密云图、磁力线分布

**自动化流程（PyAEDT）：**
```
材料构建 → 磁钢充磁 → 绕组分相 → 运动设定 →
边界设定 → 激励设定 → 损耗设定 → 求解设定 → 结果输出
```

#### 模块二：结构静力学仿真
- **工具链：** SpaceClaim + IronPython + ACTPython
- **几何：** 转子模型拉伸→命名组创建（转子/永磁体/几何面）
- **网格：** 转子细密、永磁体稀疏、隔磁桥局部加密，一阶六面体
- **材料：** 密度、杨氏模量、泊松比、极限抗拉强度（各向同性线性弹性）
- **接触：** 绑定接触 + 摩擦接触
- **输出：** 总位移、等效应力、剪应力、等效应变云图

**自动化流程（ACTPython）：**
```
材料构建 → 参考坐标系 → 循环对称 → 接触条件 →
约束 → 载荷 → 结果输出
```

#### 模块三：流固耦合热仿真
- **工具链：** Maxwell3D + SpaceClaim + PyFluent
- **几何：** 定子铁芯→绕组→等效绝缘层→冷却水道→机壳→气隙→转轴→转子铁芯与永磁体→命名组→共享拓扑
- **三维参数化：** 冷却液进出口、水道截面宽/高、水道圈数、机壳厚度
- **网格：** 多面体网格，膨胀层，狭缝/曲率控制
- **求解：** Coupled算法 + 混合初始化
- **输出：** 电机温度云图、剖面温度云图、流体流速云图

**自动化流程（PyFluent）：**
```
处理器设定 → 数学模型 → 热源 → 热系数 →
进出口条件 → 初始化 → 求解 → 结果输出
```

### 3.3 多学科数据管理（SQLite）

**9个专项数据库：**

| 物理场 | 几何库 | 材料库 | 计算库 | 结果库 |
|--------|--------|--------|--------|--------|
| 电磁场 | ✅ | ✅ | ✅ | ✅ |
| 应力场 | ✅ | ✅ | ✅ | ✅ |
| 温度场 | ✅ | ✅ | ✅ | ✅ |

**数据流转：**
```
二维几何尺寸 → 电磁场分析模型 → 电磁性能表征
二维转子模型 → 三维转子模型 → 应力场分析模型 → 机械强度表征
三维几何尺寸 → 温度场分析模型 → 热特性表征
```

### 3.4 多目标优化（OptiSlang）

- **敏感性分析：** 设计实验样本点、取样方法
- **优化变量：** 电机结构参数（定子/转子/绕组/永磁体）
- **优化目标：** 电磁性能、散热性能、机械强度、振动噪声
- **约束条件：** 几何尺寸范围、材料性能边界
- **输出：** 响应面、相关性矩阵、相关系数、Pareto图、最优参数

## 5. 仿真收敛与质量保证

### 5.1 网格质量要求

| 物理场 | 关键区域 | 网格要求 |
|--------|---------|---------|
| 电磁场 | 气隙 | ≥3层单元 |
| 电磁场 | 绕组/磁钢 | 细密网格 |
| 结构场 | 隔磁桥 | 局部加密 |
| 结构场 | 应力集中区 | 二阶单元 |
| 温度场 | 气隙 | 膨胀层 |
| 温度场 | 冷却液 | 曲率控制 |
| IGBT | 焊层 | ≥5层单元 |

### 5.2 收敛判据

| 物理场 | 判据 | 目标值 |
|--------|------|--------|
| 电磁场 | 能量误差 | < 0.5% |
| 电磁场 | 转矩脉动 | < 1% |
| 结构场 | 残余力 | < 1e-3 N |
| 温度场 | 温度变化 | < 0.1℃/步 |
| IGBT热 | 周期稳态 | 温度波动稳定 |

### 5.3 不收敛自动调整

```
1. 细化网格（气隙/焊层区域）
2. 减半时间步
3. 增加迭代次数
4. 切换求解器（如 ICCG → AMG）
5. 最多重试3次后报错
```

## 6. 工程应用模板

### 6.1 IGBT 封装可靠性分析

```
输入：IGBT型号、功率循环参数、焊层材料
流程：
  1. 三维几何建模（7层结构）
  2. 材料参数定义（含Anand模型）
  3. 功率循环载荷（4步/120s周期）
  4. 多物理场求解（温度→位移→应力）
  5. 疲劳寿命预测（Coffin-Manson + Darveaux）
  6. 参数化研究（孔洞率/焊层厚度）
输出：温度场、应力场、寿命预测、最优焊层厚度
```

### 6.2 电机多学科联合仿真

```
输入：电机类型、功率、转速、冷却方式
流程：
  1. 电磁场仿真（Maxwell2D/3D）
     → 电磁转矩、损耗、磁密分布
  2. 结构静力学仿真（Mechanical）
     → 载荷=电磁力+离心力，输出应力/应变
  3. 流固耦合热仿真（Fluent）
     → 热源=电磁损耗，输出温度场
  4. 多目标优化（OptiSlang）
     → 变量=结构参数，目标=效率/强度/温升
输出：全物理场性能报告、Pareto最优解
```

### 6.3 焊层疲劳寿命参数化扫描

```
输入：焊层材料、厚度范围、孔洞率范围
流程：
  1. 基准模型建立（指定厚度/孔洞率）
  2. 生死单元模拟孔洞
  3. 参数化扫描（厚度×孔洞率矩阵）
  4. 每个工况提取非弹性应变/应变能
  5. 计算Coffin-Manson和Darveaux寿命
  6. 绘制寿命vs参数曲线
输出：寿命分布云图、最优参数组合
```
