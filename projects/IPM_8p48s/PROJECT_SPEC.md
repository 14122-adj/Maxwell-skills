## 2. 硬约束 —— 为什么 48 槽不能照抄表 2（几何事实，非经验估计）

- 定子内径 93 mm ⇒ 12 槽时槽距 `π·93/12 = 24.35 mm`，48 槽时槽距 `π·93/48 = **6.087 mm**`，缩小到 **1/4**。
- 表 2 梨形槽槽底直径 `Bs2 = 9.5 mm`（半圆底 `Rs = 4.75`）**大于 48 槽的槽距 6.087 mm**。
  若照抄，相邻两槽的半圆底必然相交，Maxwell 几何布尔会直接报 `intersect` / non-manifold。
- 结论：**表 2 只能作为形状比例模板**。48 槽梨形槽的 `Bs0/Bs1/Bs2/Hs0/Hs1/Hs2/Rs` 必须按 48 槽重新定标，
  并同时满足：① 齿宽 ≥ 制造下限（待定，需你或标准给出）；② 轭厚 ≥ baseline 的 16 mm 或给出新判据；
  ③ 槽面积足以放下双层绕组的导体数；④ 12 槽验证过的 `Rs = Bs2/2` 关系是否仍成立需重新核对。
- **不得**用"缩小 1/4"的线性外推直接当最终尺寸然后用 FEA 自证——那仍是编数。新尺寸必须有推导链和来源。

| ID | 参数 | 为什么待定 | 需要的来源 / 做法 |

| D7 | 48 槽的网格与 401 点口径 | 槽数×4，网格量与求解时间会显著上升 | E1/E2 方法复用，但分辨率数值需按新槽距重定；记录实际 `ANALYZE_OK` 秒数 |

## 4. 执行顺序（每天一小步，一步一证据）

1. **M1'**：新建 IPM 8p48s 的 config + generator 分支，生成 `build_ipm_8p48s.py`；`-RunScriptAndExit` 真机建出 `.aedt`。
   **验收**：D1–D4 有明确来源写入本文件；48 槽 + 32 磁钢 + 96 线圈边在 `.aedt` 里数得出来；无 `intersect`。
2. **M2'**：401 点空载求解 → BEMF / THD / 齿槽；与判据对照。不合格写 FAIL，不改判据。
3. **M3'**：401 点负载 → T_avg / 脉动 / 功率平衡。
4. **M4'**：模板路径 vs 手写路径交叉；E1 网格 / E2 时间步复核。
5. **G0–G4 全绿 + 周检书面批准**后，才允许优化；探索仍按 `EXPLORATION_LOG.md` 一次一案。
6. 本项目收口后，每日任务自动切 **36 槽工业机**（Q4），本项目整体冻结为第二层 baseline。
