## 2. 硬约束 —— 为什么 48 槽不能照抄表 2（几何事实，非经验估计）

- 定子内径 93 mm ⇒ 12 槽时槽距 `π·93/12 = 24.35 mm`，48 槽时槽距 `π·93/48 = **6.087 mm**`，缩小到 **1/4**。
- 表 2 梨形槽槽底直径 `Bs2 = 9.5 mm`（半圆底 `Rs = 4.75`）**大于 48 槽的槽距 6.087 mm**。
  若照抄，相邻两槽的半圆底必然相交，Maxwell 几何布尔会直接报 `intersect` / non-manifold。
- 结论：**表 2 只能作为形状比例模板**。48 槽梨形槽的 `Bs0/Bs1/Bs2/Hs0/Hs1/Hs2/Rs` 必须按 48 槽重新定标，
  并同时满足：① 齿宽 ≥ 制造下限（待定，需你或标准给出）；② 轭厚 ≥ baseline 的 16 mm 或给出新判据；
  ③ 槽面积足以放下双层绕组的导体数；④ 12 槽验证过的 `Rs = Bs2/2` 关系是否仍成立需重新核对。
- **不得**用"缩小 1/4"的线性外推直接当最终尺寸然后用 FEA 自证——那仍是编数。新尺寸必须有推导链和来源。

### D1 —— 48 槽梨形槽 7 尺寸（closed）

推导链（`derive_slot` 的 ①–⑧ 步，逐步写在 JSON 的 `chain` 里）：

| 步 | 量 | 公式 | 值 / mm |
|---|---|---|---:|
| ① | 齿宽下限 b_t | `Bg·τ_bore/(B_t·k_fe) = 0.85×6.0868/(1.65×0.95)` | 3.301 |
| ② | 槽口 Bs0 | `min(τ−b_t, max(0.36τ, d_wire+0.4)) = min(2.786, max(2.19, 1.90))` | 2.20 |
| ③ | 颈高 Hs0 | `ceil(max(3·t_lam,1.0)+0.1, 0.1)` | 1.20 |
| ④ | 肩宽 Bs1 | `Bs0+0.5`（x1 处齿宽 3.544 ⇒ B_t 1.537 T） | 2.70 |
| ⑤ | 槽身宽 Bs2 | `ceil(2·d_wire+0.5, 0.1)`（双层各 2 根 Ø1.5 并排 + 单边 0.25 绝缘） | 3.50 |
| ⑥ | 斜肩高 Hs1 | `ceil((Bs2+1.04·b_t)·N/(2π) − (R_bore+Hs0), 0.1)`（4% 冲剪余量） | 5.30 |
| ⑦ | 槽底半径 Rs | `Bs2/2`（半圆底与直身**相切恒等式**，端点重合已由 `test_i1_tangency_holds` 钉住） | 1.75 |
| ⑧ | 槽深 Hs2 | `(R_out−h_yoke) − R_bore = (75−16) − 46.5`，轭厚沿用 baseline 16.0 | 12.50 |

结果与自检：槽面积 **39.20 mm²**（环带实切 38.76）、齿部最窄 **3.438 mm @ r=53.0**
（B_t 1.587 T ≤ 1.65）、轭部 B_yoke **1.021 T** ≤ 1.45、相邻槽底净距 3.99 mm、
线圈（0.86 内缩）两层各 **13.88 mm²**。铜耗预算：J=6 A/mm²、fill 0.55 时需槽
37.78 mm² ≤ 39.20 ⇒ PASS（ρ 取 75 °C 的 2.05e-8 Ω·m）。
`Rs = Bs2/2` 在新尺寸下**仍然成立**，且是几何恒等式而非经验关系（曲线端点与直身边必须重合）。

### D2 —— 双层绕组 / 槽内切向对称排布（closed，11-22 修订几何排布）

q = 48/(8×3) = 2，槽距电角 30°，**节距 y=5 槽（150° 电角，短距 1 槽）**，
60° 相带序列 `A A C C B B A A C C B B`（12 槽一循环，48 = 4×12）。
双层：线圈 k 的一条边在槽 k、另一条边在槽 k+5（模 48）⇒ 96 个边。
**槽内排布（11-22 两次修订）**：同一槽内两条边按切向 y=0 对称并排，
中间 0.4 mm 绝缘带，径向 x 覆盖同样范围 ⇒ 到气隙等距，**不是一远一近**；
截面为**矩形 4 点**（非异形切分）。单一矩形受半圆底 + 槽绝缘边距约束，
最优 x[48.4,58.2] / y[0.2,1.2] ⇒ **9.800 mm²/条**（旧异形 12.301，−20%），
边距 0.2023 mm。**面积缩水是本轮工程代价**：铜耗/BEMF 必须由 M2' 实测，
匝数按 `N_ph=16·cps` 反推，不许靠伸出槽外保面积。
实现 `ipm_geom.py::coil_layers`（`shape='rectangle'`），自检 `test_i1_coil_inside_slot`。
`k_w1 = 0.9330`、`k_w5 = k_w7 = 0.0670`（短距把 5/7 次压到基波的 7.2%）、
三相基波互差 120.00°、三倍频在线电压中严格抵消。
相属表：`projects/IPM_8p48s/WINDING_TABLE.md`（48 行×上下层），机读版
`projects/results/ipm8p48s/i2_winding_sides.csv`（96 行）。

### 7.1 气隙圆环 —— 精确几何（由现有配置推导，非拍脑袋）

| 量 | 公式 | 值 |
|---|---|---:|
| 定子内径 / 外圈半径 | `stator_id` / `stator_id/2` | 93.000 / **46.5000 mm** |
| 转子外径 / 半径 | `rotor_od` / `rotor_od/2` | 91.650 / **45.8250 mm** |
| 气隙 | `(93−91.65)/2` | **0.6750 mm** |
| 环内半径 | `rotor_od/2 + airgap/2` | **46.1625 mm** |
| 环内径 | `rotor_od + airgap` | **92.3250 mm** |
| 环厚度 | `airgap/2` | **0.3375 mm** |

- 材料 vacuum，**独立实体**（Name 建议 `AirgapRing`），外半径 46.5 与定子内径共面、
  内半径 46.1625 与气隙中线重合。
- **与 Band 的重叠**：现有 Band 已占气隙且绑定运动（`AssignBand Move Type=Rotate`）。
  用户选"新增独立空气环"，因此**必须先把 Band 改为不占实体**：
  将 Band 对象半径收进转子表面以内（例如 R≤45.80，贴转子 OD），
  或把运动带绑到转子对象本身，使 `AirgapRing` 成为气隙里唯一的独立环。
  **两条几何不得重叠，否则 Maxwell 直接 intersect**。这是 M1' 的硬验收项。

### 7.2 磁钢外移 —— I16 的根因修复（真机已证 FAIL，必须做）

- 现状 `v_single=(26,38,13,3)`：磁钢外角到 OD **8.356 mm**，实测桥区磁密仅 **0.085 T**，
  气隙 Bg **0.063 T**（解析预测 0.59 T 的 11%），BEMF **4.2552 V**（判据 118–145 V，FAIL）。
  根因 I13/I16：桥太厚不饱和 → 磁通从极间短路，不到气隙。
- **外移目标**：apex 26 → **33 mm**（外移 7 mm），OD 桥 **1.549 mm**（≤2.0 判据），
  同组两腿 3.0 mm、轴孔 16.5 mm、16 块、几何自检仍 PASS。
  解析扫描已验证 apex=32→OD 2.525（不够）、33→1.549（达标）、33.5→1.060（<1.5 机械下限 FAIL）。
- **已知限制（诚实记录）**：单层 V 的极间桥恒在 10 mm 以上，与账本 I16 的"极间≤2.0"
  判据不可兼得——那是极距几何决定的，不是 apex 变量。**周检须复核 I16 该条判据是否定错**；
  本轮只按 OD 桥 ≤2.0 推进，不擅自改判据。
- 外移后必须重跑 M1'（几何自检 + 真机无 intersect）与 M2'（Bg ≥0.45 T、BEMF 回升），
  不得用解析 0.59 T 代替实测。

### 7.3 三工况激励 —— winding 现状与修正

**现状（已读代码确认）**：`ipm_build.py:359-360` 把 `AssignWindingGroup` 的
