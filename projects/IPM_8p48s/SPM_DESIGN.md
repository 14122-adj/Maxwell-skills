# SPM 贴片式平行充磁 — 设计定源（2026-11-25）

> 用户要求：在 IPM 8p48s（25 N·m）基础上做**贴片式永磁体平行充磁**，同样 25 N·m，
> 其他参数不变；必要变更自行计算最佳值。任务写入每日迭代 + 周检。
>
> 本文是**定源 + 待验证**文档，不是 FEA 结论。所有数值标注 `assumption=待验证`，
> 真机 401 点未跑之前不得当作性能数据（反自演条款）。

## 1. 与 IPM baseline 的差异（只改转子，定子/绕组/气隙不动）

| 项 | IPM 8p48s（已验证） | SPM 贴片（本设计） | 状态 |
|---|---|---|---|
| 极数 / 槽数 | 8 / 48 | 8 / 48 | 不变 |
| 定子 OD / ID | 150 / 93 mm | 150 / 93 mm | 不变 |
| 气隙（半径） | 0.675 mm | 0.675 mm | 不变 |
| 叠厚 | 160 mm | 160 mm | 不变 |
| 绕组 | 梨形槽、cps=10、短距 5 | 同左 | 不变 |
| 电流 | Imax=13.856 A, φ_abs=90° | 同左（初值） | 待验证 |
| 转子铁芯 OD | 91.65 mm（r=45.825） | **86.89 mm**（r=43.445） | **变更** |
| 磁钢拓扑 | 16 块单层 V，每块 13×2.8 | **8 块贴片**，厚 2.38，极弧 0.85 | **变更** |
| 充磁方向 | V 型交替（奇数极外法线） | **平行充磁**，每极恒定矢量 N/S 交替 | **变更** |
| 目标转矩 | 25 N·m | 25 N·m | 不变 |

## 2. 磁钢厚度推导（磁通等效，assumption=待验证）

```
IPM 每极磁钢截面 = 582.4 mm² / 8 = 72.80 mm²
SPM 极距 @ r=45.825   = π × 91.65 / 8 = 35.991 mm
极弧宽（α=0.85）      = 35.991 × 0.85 = 30.592 mm
等效厚度 t_pm         = 72.80 / 30.592 = 2.380 mm
```

**为什么转子铁芯必须缩径**：贴片磁钢贴在铁芯表面并占据原气隙空间。若铁芯 OD 保持
91.65 mm，磁钢外径会到 91.65+2×2.38 = 96.41 mm > 定子内径 93 mm，**负气隙、几何干涉**。
保持气隙 0.675 mm 不变 ⇒ 铁芯 OD = 91.65 − 2×2.38 = **86.89 mm**。

**气隙环拓扑沿用 I17**：Band 为整圆 R=43.445+0.3375=43.7825 mm（气隙中线），
AirgapRing 外 R=46.5 / 内 R=43.7825，厚 2.7175 mm。这里气隙环比 IPM 厚，
`Mesh_Airgap` 需相应加密：MaxLength 0.15 mm ⇒ 2.7175/0.15 ≈ 18 层，单元数会显著上升
（初估 AirgapRing 从 13690 → 5 万+，总单元可能翻倍），**求解时间预算按 1.5–2× 估**。

## 3. 最大风险与处置

| 风险 | 解析预兆 | 处置 |
|---|---|---|
| **转矩超 25 N·m** | SPM 等效 Bg ≈ `Br·t/(t+μr·g)` = `1.23×2.38/(2.38+1.05×0.675)` ≈ **0.95 T**，比 IPM 实测 0.6189 T 高 **53%** | 单变量扫磁钢厚度 **2.0 / 2.38 / 2.8 mm**，取 T_avg 落 22.5–27.5 的档；**不改电流凑数**（改电流会污染 25 N·m 判据的可比性） |
| BEMF 出窗 | BEMF ∝ Bg，可能从 133.7 V 升到 >145 V | 同上；BEMF 判据 118–145 V 保持 |
| 平行充磁方向错 | 通用 `pm_builder.py` 的 SPM 分支把 8 块矢量设为 0°,45°,90°…**辐射状**，缺 N/S 180° 交替 —— 物理上不成立 | **2026-11-25 已修复**为 `sign=+1/−1` 乘该极轴的 `cosθ,sinθ`；注意相邻极轴差 45°，不是相邻矢量严格反号 |
| 齿槽变大 | 表贴磁钢无 V 型聚磁，极弧 0.85 可能抬高齿槽 | 空载 M2 验齿槽 ≤1.25 N·m；超标则扫极弧 0.8/0.85/0.9 |
| 转子惯量变化 | 铁芯缩径、磁钢外移，J 会变 | 只影响 M4 起动，不进 M1'–M3' 判据；若做 M4 需重算 J |

## 4. 单变量实验顺序（写入每日任务）

```
S0 先把 IPM baseline 锁住（M1'/M2'/M3'/斜槽证据全留，不得回退）。
S1 新建 projects/IPM_8p48s/spm_build.py：转子铁芯 OD 86.89 + 8 块贴片 + 平行充磁交替；
   几何自检：8 块磁钢、无 intersect、气隙 = 0.675、117 sheet 量级。
S2 M1_SPM 空载：Bg/BEMF/齿槽 401 点 + mesh JSON（气隙层数 ≥2）。
S3 M3_SPM 负载：Imax=13.856 A 固定，t_pm=2.38 先跑 401 点，看 T_avg/峰峰/BEMF。
S4 若 T_avg>27.5：t_pm 改 2.0 重跑（单变量，其余不动）；若仍高改 1.6。
   若 T_avg<22.5：t_pm 改 2.8 重跑。
S5 峰峰 >10% 时先 FFT 定谐波阶次，再考虑极弧/斜槽；不得直接改电流。
S6 每步 FAIL 写账本 I29+，不改判据、不删数据。
```

## 5. 验收口径（与 IPM 同，不降标准）

- 几何：无 intersect、sheet 数量合理、气隙 0.675 mm 实测确认
- 网格：`mesh_<case>.json`，AirgapRing 层数 ≥2（契约 §9.2）
- 空载：Bg 0.70–0.90 T（G4）、BEMF 118–145 V、齿槽 ≤1.25 N·m
- 负载：T_avg 22.5–27.5 N·m（目标 25）、峰峰 ≤10%、主谐波 ≤5%
- 全部 401 点，解析只作交叉校验
