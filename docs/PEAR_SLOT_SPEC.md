# 梨形槽规格（表 2 尺寸，25 N·m 8p12s）

> 来源：用户 2026-11-14 提供的表 2「定子槽尺寸」与图 1-1「梨形槽结构示意图」。
> 目标：把模板 `scripts/main.py::_gen_geometry` 的 `pear` 分支从"浅梨形（8.05 mm）"
> 改为按本表参数化的真梨形槽，并用于 25 N·m 机型的 FEA 齿槽优化。

## 1. 给定尺寸

| 参数 | 符号 | 值 / mm | 说明 |
|---|---|---:|---|
| 槽口宽 | Bs0 | **0.8** | 靠近定子内径的开口宽 |
| 槽口高 | Hs0 | **1.5** | 窄颈高度 |
| 槽口斜肩高 | Hs1 | **1.8** | 由 Bs1 斜扩到 Bs2 的高度 |
| 槽深 | Hs2 | **12.5** | 从定子内径到圆形槽底**最底端**的总深 |
| 圆形槽底宽度 | Bs1 | **6.0** | 肩部/斜肩起点的宽 |
| 圆形槽底直径 | Bs2 | **9.5** | 槽底半圆直径（Rs = 4.75） |

## 2. 径向坐标（x = 半径方向，y = 切向）

定子内径 `R_bore = 46.5`；槽口从 `x0 = R_bore - 0.2 = 46.3` 起（0.2 mm 重叠，避免与内孔圆弧相切）。

| 位置 | 公式 | 值 / mm | 含义 |
|---|---|---:|---|
| x0 | R_bore − 0.2 | 46.3 | 槽口起点（切进内孔 0.2） |
| x1 | R_bore + Hs0 | 48.0 | 颈末 / 肩部 |
| x2 | R_bore + Hs0 + Hs1 | 49.8 | 斜肩末 / 直身起点 |
| Rs | Bs2 / 2 | 4.75 | 槽底半圆半径 |
| x3 | R_bore + Hs2 − Rs | **54.25** | 圆心 |
| x4 | R_bore + Hs2 | **59.0** | 槽底最底端 |
| 轭部 | R_stator − x4 | 16.0 | 75 − 59 |

> **假设**：`Hs2` 按「内径→槽底最底端」的总深理解。
> 若本意是「内径→圆心」，则 x3 = 59.0、x4 = 63.75、总深 17.25、轭部 11.25；
> 只需把 `x3 = R_bore + Hs2`、`x4 = x3 + Rs` 改掉即可，其余不变。

## 3. 轮廓点（逆时针，11 点 + 闭合）

| # | 坐标 |
|---:|---|
| 0 | (x0, −Bs0/2) = (46.3, −0.4) |
| 1 | (x1, −Bs0/2) = (48.0, −0.4) |
| 2 | (x1, −Bs1/2) = (48.0, −3.0) |
| 3 | (x2, −Bs2/2) = (49.8, −4.75) |
| 4 | (x3, −Bs2/2) = (54.25, −4.75) |
| 5 | (x4, 0) = (59.0, 0) |
| 6 | (x3, +Bs2/2) = (54.25, +4.75) |
| 7 | (x2, +Bs2/2) = (49.8, +4.75) |
| 8 | (x1, +Bs1/2) = (48.0, +3.0) |
| 9 | (x1, +Bs0/2) = (48.0, +0.4) |
| 10 | (x0, +Bs0/2) = (46.3, +0.4) |
| 11 | 回到 0（闭合） |

**段**：
- Line 0-1（颈侧）
- Line 1-2（肩部台阶）
- Line 2-3（斜肩）
- Line 3-4（直身）
- **Arc 4-5-6**（`StartIndex:=", 4, "NoOfPoints:=", 3`，半圆底，圆心 x3、半径 Rs）
- Line 6-7、7-8、8-9、9-10、10-11（另一侧 + 闭合）

## 4. 面积与几何校验

| 项 | 公式 | 值 |
|---|---|---:|
| 颈 | Bs0·(x1−x0) | 1.36 mm² |
| 斜肩 | (Bs1+Bs2)/2·Hs1 | 13.95 mm² |
| 直身 | Bs2·(x3−x2) | 42.275 mm² |
| 半圆底 | π·Rs²/2 | 35.437 mm² |
| **槽面积** | 合计 | **93.02 mm²**（±2%） |
| 槽距（内径处） | 2π·R_bore/12 | 24.347 mm |
| 齿宽（槽最宽处） | 槽距 − Bs2 | 14.847 mm |
| 线圈面积（0.88 内缩） | ≈0.7744×槽面积 | ≈72.0 mm² |
| 槽满率 | 线圈/槽 | ≈0.774 |

- 线圈按梨形轮廓 **0.88 向形心内缩**；弧段需加采样点（≥8 点）再内缩，
  避免线圈下缘切进半圆底。40 导体/槽边，校核槽满率 ≤0.78。
- 槽口 0.2 mm 重叠保留（与现模板/m4 同口径），否则内孔圆弧相切会触发
  `Non-manifold vertices`。

## 5. 实施步骤

1. **模板** `scripts/main.py::_gen_geometry` 的 `pear` 分支：
   - `x1 = r_bore + Hs0`、`x2 = r_bore + Hs0 + Hs1`（**从 r_bore 起算**，不是 x0）；
   - 新增 `x3 = r_bore + Hs2 - Rs`、`x4 = r_bore + Hs2`；
   - 11 个 PLPoint + 10 段（含 `Arc` StartIndex 4 / 3 点）；
   - `_slot_pts` 同步为 11 点（线圈内缩用）。
2. **配置** `pmsm_config.py` / CLI：25 N·m 机型设
   `slot_type=pear, slot_Bs0=0.8, slot_Hs0=1.5, slot_Hs1=1.8, slot_Hs2=12.5,
   slot_Bs1=6.0, slot_Bs2=9.5, slot_Rs=4.75`。
3. **线圈**：0.88 内缩 + 弧段采样；面积/满率校验；必要时调线径/匝数。
4. **重生成** → `gen_maxwell_model.py` → `tpl_solve_noload.py` 真机空载。
5. **对比基线**（当前手写/模板一致值）：
   - BEMF 相 RMS **118.8832 V**；齿槽峰峰值 **6.84307 N·m（27.37%）**；
   - 负载 `T_avg` **22.3344 N·m**（−10.66%）；
   - 报告 §11 的 FEA 交叉校验同步更新。
6. 若梨形槽单独不能把齿槽压到 5% 以下，继续斜槽/极弧/槽口 FEA 扫描。

## 6. 验收

- 槽面积 **93.0 ±2%**；线圈面积 **72 ±5%**；槽满率 ≤0.78；无 `intersect` / `Non-manifold`。
- BEMF 相 RMS 与基线偏差 **≤10%**；齿槽峰峰值 **≤6.843 N·m**（目标 ≤1.25 N·m / 5%）。
- 负载 `T_avg` 仍落在 25 N·m 的 **±20%**。
- `pytest`/`ruff` 全绿；模板与生成物 `--check` 无漂移；`DESIGN_PROGRESS.md` /
  `WEEKLY_GOALS.md` / 报告同步更新。
