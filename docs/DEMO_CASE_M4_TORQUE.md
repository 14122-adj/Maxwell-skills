# 演示案例：让转矩从 0 升到 25 N·m 并稳定

> 2026-11-25 实测沉淀。案例价值不在"画出了曲线"，而在**先分清工况口径、再选激励方式**。
> 同一台电机，三种做法给出三种完全不同的曲线，其中两种物理上就不可能达标。
> 可独立用作演示脚本，也可作为电机起动仿真的判据参考。

## 1. 问题与结论

**提问**：「为什么没有转矩从零开始上升的转矩曲线？」「到底有没有办法把转矩图形从零开始到 25？」

**结论先行**：有，但必须用**稳态口径 + 电流软启动**。机械瞬态 + 变频起动给不出"稳定在 25"——
PMSM 无阻尼绕组，开环 V/f 没有转差补偿，负载角随转速漂移，转矩必然摆动。

| 目标 | 正确口径 | 命令行 |
|---|---|---|
| 转矩 `0 → 25` 后**稳定** | 恒转速 1500 rpm + 固定 100 Hz + 电流软启动 | `--steady --soft-start 0.02` |
| 转速 `0 → 1500`（看起动） | 机械瞬态 + 变频爬坡 | `--mode chirp`（不要加 `--steady`） |

**两者不能同时满足"转矩稳定在 25"**，这是物理限制，不是参数问题。

## 2. 三层根因（逐层否证，全部有真机证据）

### 第一层：稳态工况下 t=0 就是额定转矩

M1'–M3' 全部设 `Consider Mechanical Transient=False` + `Angular Velocity="1500rpm"`，
求解器从不积分 `J·dω/dt = T_em − T_load`。风力/电流源在 t=0 就灌满 `Imax·sin(φ)`，
磁钢剩磁也早已预置。

硬证据：`D:/ANSYS_Run/csv_ipm_m3_cps10/tq_load.csv` 首行 `0, 26.5808397855413`。
**稳态曲线里根本不存在起动段**，找"从零上升"是找错对象。

### 第二层：机械瞬态 + 固定频率开环，转子起不来

| 量 | 实测 |
|---|---:|
| 转速峰值 | 59.3 rpm @122.5 ms |
| 转速末段 | −8.1 rpm |
| 转矩峰 / 谷 | +33.84 / −33.88 N·m（均值 0.381） |
| 位置末值 | 358.72°（抖回原位） |

PMSM 没有阻尼绕组，定子磁场以 1500 rpm 旋转时静止转子只能被正负转矩原地拉扯。
异步机能自起动靠鼠笼，PMSM 必须靠变频器爬坡 / 阻尼笼 / 编码器闭环。

### 第三层：位置反馈走不通

试过 `i = −Imax·sin(p·Moving1.Position·π/180 + φ)`（本机 `Moving1.Position` 单位是 **deg**）：
转矩仅 **55 µN·m**、位置末值 **0.00029°**。根因是 `Moving1.Position` 在 winding 电流表达式里
**未被实时求值**（当成常量 0），三相退化为固定直流，合成磁动势静止。本机 2021.1 不可用。

### 补充：变频爬坡能起动，但转矩稳不住

| 爬坡时长 | 转速峰值 | 转速末段 | 转矩峰/谷 | 判读 |
|---|---:|---:|---:|---|
| 0.12 s | 1379 rpm | 1336 rpm | +32.47 / −33.10 | 失步（滑差 10.9%） |
| 0.18 s | 1687 rpm | 1588 rpm | +32.75 / −33.40 | 过冲后同步振荡 |

同步振荡周期约 80 ms ↔ 12.5 Hz，与 `√(P_max·p/(J·ω_s)) ≈ 16.6 Hz` 同量级，是机电自由振荡。
要压住需 `D_critical ≈ 0.77 N·m·s/rad`，比真实轴承+风阻大约 600 倍——不可行。

## 3. 正解：电流软启动

在电流表达式前乘一个时间因子，等价于真实驱动器的电流环上升时间：

```
i(t) = −Imax · min(t / T_soft, 1) · sin(2π·100·t + φ)
```

- `t=0` → `min=0` → `i=0` → `T_em ≈ 0`
- `t ≥ T_soft` → `min=1` → `i=Imax` → `T_em = 25 N·m`

`T_soft = 0.02 s`（20 ms，伺服驱动器电流环建立时间量级）。
**这不是凑图**：软启动是变频器标准功能，只改建立过程，不改稳态。

### 实测结果（401 点 / 18 分 11 秒）

| 量 | 值 |
|---|---:|
| 转矩 `t=0` | **3.46e-05 N·m**（精确为零） |
| 转矩峰值 | 27.516 N·m（超调 6.7%） |
| 末段稳态 | **25.788 N·m** |
| 转速 | 恒定 1500 rpm |
| 图 | `projects/results/ipm8p48s/m4_start_curve_steady.png` |

形态：`0 → 25` 线性上升（0–20 ms）→ 之后保持，只有 ±1.5 N·m 的齿槽纹波。

## 4. 复现命令（完整可运行）

```bash
cd D:/桌面/ANSYS MaxWell_skill/projects/IPM_8p48s

# 建模 + 求解 + 摘要（约 18 分钟，机械瞬态口径的 1.1×）
python ipm_m4_start.py --case steady --steady --bemf 133.7364 \
       --soft-start 0.02 --stop 0.2s --dt 0.0005s --run

# 出图（带数值标注）
python ipm_m4_plot.py --case steady
```

要点：
- `--bemf 133.7364` 是**当前几何**实测相 BEMF；旧几何的 127.744 会把 Imax 从 13.86 A 抬到 14.50 A。
- `--steady` 必须给，否则走机械瞬态，转矩不可能稳定。
- `--soft-start 0` 是默认值，保持历史 M4 数据逐字可比。

## 5. 在主桌面打开 Maxwell 演示（不关窗口）

用 `-RunScript`（**不带** `AndExit`）可在主桌面打开 GUI 并保持运行：

```bash
"D:/Program Files/AnsysEM/AnsysEM21.1/Win64/ansysedt.exe" \
    -RunScript "D:/ANSYS_Run/open_steady_gui.py"
```

`open_steady_gui.py` 做三件事：`OpenProject` → `SetActiveDesign` → `CreateReport("TqM4", ...)`
显示转矩曲线；末尾不调 `Exit()` / `Save()`，窗口保持打开。

**三个坑（都踩过）**：

| 坑 | 现象 | 处置 |
|---|---|---|
| 脚本里调 `oDesktop.AddMessage` | `-RunScript` 启动阶段抛 OLE 异常，`OpenProject` 之前就中断，窗口是空的 | 删掉所有 `AddMessage`，改用文件日志 |
| 残留 `.aedt.lock` | 锁里记着已死进程的 PID，`OpenProject` 卡住不动 | 关掉所有 `ansysedt.exe` 后删 `<project>.aedt.lock` 与 `.asol*.semaphore` |
| 已有同名报告 | `CreateReport("TqM4")` 自动改名成 `TqM5`，曲线对但标题不对 | 先用 `GetAllReportNames()` 判重，或接受 TqM5（内容相同） |

AEDT 是**单实例**（localhost:1055）：虚拟桌面和主桌面同时开同一工程会抢 `.asol_priv` 锁。

## 6. 判据与陷阱（演示时必须说明）

1. **转矩首点不为零是物理正确的**——起动瞬间电流已建立、气隙磁场已存在。用户说的"从零"指**转速从零**，
   若是要"转矩从零"就必须显式加软启动。
2. **只导 `Moving1.Torque` 会漏判**：M4 首跑转矩在 ±33 N·m 之间摆，看着像"起动"，
   但 `speed.csv` 证明转子根本没动。**起动工况必须同时导 `Moving1.Speed`**。
3. **判断"跑完"要看 CSV 存在 + solve 日志有 `ANALYZE_OK`**，不看 `.aedt` 时间戳，也不看 AEDT GUI 曲线——
   GUI 会实时画中间结果，2026-11-25 曾把算到 225 ms 的半成品当成最终曲线。
4. **长窗口工况不许与 401 点工况串在同一天**：0.5 s / 1000 点实测超 55 分钟，0.2 s / 401 点约 16–18 分钟。
5. 读 CSV **先看表头单位**：IPM 导出过 `uNewtonMeter`，按 N·m 读会放大 1000×。

## 7. 附：气隙网格敏感性（同日顺带闭环）

给 `AirgapRing` 单独加 `AssignLengthOp MaxLength=0.15mm`（1.48 层 → 2.58 层）后：

| 项 | 1.48 层 | 2.58 层 | 变化 |
|---|---:|---:|---|
| T_avg | 27.0306 N·m | **25.8068** | −4.5%（更接近 25） |
| 峰峰值 | 14.0757% | **14.0075%** | −0.07 pp（几乎不变） |
| 主谐波 h=12 | 5.9393% | 5.8872% | −0.05 pp |

结论：网格影响的是**绝对值**，`T_avg` 更接近 25；**不是脉动主因**。
斜槽 0.75 的 3.29% 结论成立，14% 是真实的槽谐波问题。
