# 电机工程验收标准（25 N·m 8p12s SPMSM）

> 目的：把「技能能跑」与「电机设计能投入工程」分开。技能可用 ≠ 设计合格。
> 所有判据必须有文件/日志/CSV 证据；禁止用解析值替代 FEA、禁止用试算/单点数据下结论。
> 本文件是每日任务与周检的共同判据；任何一条不达标，必须在 `PROBLEM_LEDGER.md` 留痕。

## 0. 两级判定

| 判定 | 含义 | 通过条件 |
|---|---|---|
| **技能可用** | skill 能在真机 Maxwell 中完成建模→求解→导出→报告 | G0–G3 全绿；401 点全时长解；模板/手写路径等价 |
| **设计合格** | 这台 25 N·m 电机达到工程可交付水平 | G4–G8 全绿；齿槽 ≤5%、转矩脉动 ≤10%、效率 ≥93.8%、热/退磁/制造全过 |
| **流程合规** | 每日任务按闭环执行，没有自演/越权探索 | G9：401 点、先 green 后优化、账本更新、失败保留、每天 push、探索经周检批准 |

## 3. 数值可信度（G0/G3/G4 的硬检查）

| 检查 | 方法 | 通过判据 |
|---|---|---|
| 网格无关性 | 3 档网格（粗/中/细），同一工况 | 转矩/BEMF 变化 <2% |
| 时间步无关性 | 50 µs vs 25 µs | 转矩/BEMF 变化 <2% |
| 能量守恒 | P_in = P_mech + P_cu + P_fe + P_PM + P_mech_loss + P_stray | 偏差 <5% |
| 磁通连续性 | 气隙/齿/轭磁密路径积分 | 无异常跳变/饱和 |
| 对称性 | 三相 BEMF 不平衡 | ≤2% |
| 边界正确性 | `VectorPotential=0` 只在外圆，不在孔边 | `Edges` 数量=1（切孔前） |
| 单位/量纲 | mm、s、Wb、N·m；µs/mN·m 换算 | 与 CSV 表头一致 |
| 独立重算 | 另写脚本从磁链 CSV 重算 BEMF | 与报告偏差 <2% |
| 双路径 | 模板 vs 手写 | BEMF/齿槽/负载 ±10% |
| 试算隔离 | 试算解 vs 全时长解 | 只用 401 点全时长；试算仅用于“能解”判断 |

## 4. 反「自编自演」规则（每次迭代必须遵守）

1. **解析值只能作交叉校验**，不能填 FEA 的空缺；报告里必须分列 `analytic` / `FEA`。
2. **禁止用试算/单点数据下结论**：至少 1 个电周期（10 ms）或 401 点；5 点/200 µs 只能判“能解”。
3. **禁止事后改判据**：判据在实验前写死；不达标就记 fail，不改阈值、不换口径。
4. **禁止挑选案例**：探索时失败/异常的工况也要入 `EXPLORATION_LOG.md`，不许只报最好的。
5. **每个数字必须有证据**：文件路径 + 行号/键值/CSV 行数/日志；没有证据的数字视为无效。
6. **物理 sanity check**：BEMF ∝ 转速×匝数×磁通；转矩 ∝ 电流×Kt；损耗和 ≈ 输入−输出；符号/方向正确。
7. **结果太好要怀疑采样**：齿槽 0.4 N·m（5 点）→ 实际 6.843 N·m；结果太差要查模型（材料/边界/ModelDepth/磁化方向）。
8. **独立复核**：关键结论至少用第二种方法复算（模板 vs 手写、解析 vs FEA、独立脚本 vs 工作区脚本）。
9. **保留失败记录**：`PROBLEM_LEDGER.md` 里 fail 的条目不得删除；关闭必须写“证据 + 验收值”。
10. **已知误判清单**：Band 薄环 / `EditSetup` 丢运动 / 齿槽 1.6% 三条已被 `6fca72c` 推翻，不得再写。

## 5. 标准证据格式

```
[日期] [阶段] [指标] = [值] [单位]
证据: [文件:行/键] 或 [CSV 行数/统计口径]

备注: [假设/局限/下一步]
```


## 6. 周检监督清单（流程合规）

周检除了验数，还要监督每日任务是否按 `docs/DAILY_LOOP.md` 执行：

1. 每日是否从 `PROBLEM_LEDGER.md` 选一个最高优先级问题？
2. 标准流程是否 401 点？是否先 green 再优化？
3. 是否拿解析填 FEA 空缺、拿试算/5 点当性能、事后改判据、删失败案例？
4. `PROBLEM_LEDGER` 的 fail 是否保留？关闭是否有证据？
5. 是否每天 commit/push？是否 `git add -A` 扫入脏文件？
6. 探索是否在 G0–G4 green **且周检批准**后才开始？未批准是否标 LOCKED？
7. 连续 2 天无进展的问题是否标 `blocked` 并换路径？

**流程违规**（任一）：在坏模型上优化、用解析填 FEA、试算当性能、改判据、删失败案例、越权探索、`git add -A` 扫脏文件。
处理：周检在报告中标「流程不合规」，暂停探索，更新每日任务 prompt 纠正；连续两周违规 → 降级为「技能可用 / 流程待修」。
